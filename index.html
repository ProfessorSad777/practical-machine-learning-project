Objective

The outcome is classe, which records whether a participant performed a barbell lift correctly (A) or made one of four common mistakes (B-E). The predictors are measurements from accelerometers on the belt, arm, forearm, and dumbbell. The aim is to build a model with a realistic estimate of out-of-sample performance and apply it to the 20 quiz cases.

Data preparation

The original data contain 19,622 training observations and 160 columns. I removed the first seven columns because they are row identifiers, participant names, timestamps, and window-management fields rather than sensor measurements. Predictors with at least 95% missing values, nonnumeric fields, and zero-variance fields were also removed. This left 52 complete numeric sensor predictors.

training_raw <- read.csv(training_url,
                         na.strings = c("NA", "#DIV/0!", ""))
testing_raw <- read.csv(testing_url,
                        na.strings = c("NA", "#DIV/0!", ""))

candidate_names <- names(training_raw)[8:(ncol(training_raw) - 1)]
usable <- vapply(training_raw[candidate_names], function(x) {
  is.numeric(x) && mean(is.na(x)) < 0.05 &&
    length(unique(na.omit(x))) > 1
}, logical(1))

predictor_names <- candidate_names[usable]
model_data <- training_raw[c(predictor_names, "classe")]
quiz_data <- testing_raw[predictor_names]

No imputation or principal-component transformation was needed because the selected predictors were complete. Keeping the original measurements also preserves interpretability.

Model and cross-validation

I reserved 25% of the observations as a stratified validation set. A random forest was chosen because the relationship between body motion and exercise quality is nonlinear and includes interactions among sensors. It handles these patterns without manually specifying interaction terms and is robust to correlated predictors.

The remaining 14,716 observations were used for model fitting. Five-fold cross-validation estimated performance during training. The number of variables considered at each split was 7, approximately the square root of 52, and 500 trees were grown.

in_build <- createDataPartition(model_data$classe,
                                p = 0.75, list = FALSE)
build <- model_data[in_build, ]
validation <- model_data[-in_build, ]

control <- trainControl(method = "cv", number = 5,
                        savePredictions = "final")
rf_fit <- train(
  classe ~ ., data = build, method = "rf",
  trControl = control,
  tuneGrid = data.frame(mtry = 7),
  ntree = 500, importance = TRUE
)

The fold-to-fold standard deviation was 0.16 percentage points. The consistently high agreement made a much larger tuning search unlikely to yield a meaningful practical improvement.

Out-of-sample performance

The untouched validation set contained 4,906 observations. Accuracy was 99.59%, corresponding to an estimated out-of-sample error of 0.41%. This agrees closely with cross-validation and the random forest’s 99.48% out-of-bag accuracy, so there is little evidence that the fitted model is over-optimistic.

Predictions for the 20 quiz cases

The final model was refitted on all 19,622 labeled observations before predicting the quiz set.

final_model <- randomForest(
  classe ~ ., data = model_data,
  mtry = 7, ntree = 500, importance = TRUE
)
quiz_predictions <- predict(final_model, quiz_data)

Conclusion

The random forest separated the five exercise classes with low and consistently estimated error. The close agreement among five-fold cross-validation, out-of-bag performance, and the untouched validation set supports an expected out-of-sample error of about 0.4% for observations drawn under similar conditions.
